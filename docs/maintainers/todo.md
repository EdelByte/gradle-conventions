## Missing Tusker conventions — Spring Boot 3

Compared local `../tusker/src/main/kotlin/` with the registered plugins and implementations in this repository on 2026-11-19. Source filenames below are relative to that Tusker directory. Scope includes Spring Boot 3 variants and shared, Boot-independent plugins; Spring Boot 2-specific variants are excluded.

Existing equivalents: `tusker-java-spring3-core` is covered by `java-core` plus `spring-boot-base`; `tusker-spring3-service`, `tusker-spring3-int-test`, `tusker-jacoco`, and `tusker-open-rewrite` have counterparts in `spring-boot-service`, `spring-boot-int-test`, `jacoco`, and `open-rewrite`. These are convention-level mappings, not claims of exact dependency/version parity.
Intentional split: `tusker-kotlin-spring3-core` is represented by applying `kotlin-core` together with `spring-boot-base`. Kotlin and Spring conventions remain separate by design; no combined plugin migration is needed.
